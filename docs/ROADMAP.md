# Роадмап

Этапы идут по порядку; каждый заканчивается чем-то, что можно запустить и потрогать.
Сроков нет — проект делается в свободное время. Задача отмечается галочкой, когда она в `main`.

Правило: задачи следующего этапа уточняются, когда до него дошли. Дальние этапы — наброски.

## M1 — Питомец на экране

**Итог:** анимированный питомец ходит по низу экрана, его можно взять мышью и перенести.
Потребностей ещё нет.

Оверлей
- [ ] Спайк: полноэкранное прозрачное окно со SpriteKit-сценой, замер CPU/GPU/энергии в покое
- [ ] По итогам спайка подтвердить или пересмотреть решение №1 в [ARCHITECTURE.md](ARCHITECTURE.md)
- [ ] Клики проходят насквозь везде, кроме питомца
- [ ] Окно поверх обычных приложений, на всех Spaces; поведение в полноэкранных приложениях
- [ ] Пол: нижняя граница рабочей области с учётом Dock

Спрайты и анимация
- [ ] Формат манифеста анимаций (JSON) и загрузчик
- [ ] Набор-заглушка: `idle`, `walk`, `sit`, `fall`, `dragged`
- [ ] Чёткое пиксельное увеличение (nearest), отражение по горизонтали для направления

Движение
- [ ] Ходьба к точке, остановка у краёв экрана
- [ ] Перетаскивание мышью, падение с гравитацией, приземление
- [ ] Простейший случайный блуждатель (временный, заменится «мозгом» в M3)

Оболочка
- [ ] Меню-бар: показать/спрятать питомца, выйти
- [ ] `PetController` и цикл тиков; пауза сцены, когда питомец скрыт

## M2 — Тамагочи

**Итог:** у питомца есть потребности, за ним можно ухаживать, состояние переживает перезапуск.

Ядро
- [ ] Модель потребностей: сытость, энергия, настроение (+ чистота?) и скорости убывания
- [ ] `Mood` — производное состояние с порогами и гистерезисом
- [ ] Сон: засыпание, восстановление энергии, пробуждение
- [ ] `WorldEvent` / `PetCommand` — контракт между ядром и оболочкой
- [ ] Офлайн-догон с ограничением сверху
- [ ] Тесты сценариев («6 часов без еды», «ночь сна», «неделя офлайн»)

Сохранение
- [ ] `PetState` в JSON, версия схемы, сохранение по таймеру и при выходе
- [ ] Поведение при битом/старом файле

Уход
- [ ] Кормление: еда появляется на сцене, питомец подходит и ест
- [ ] Поглаживание: распознать движение мыши по питомцу, реакция
- [ ] Окно статуса: шкалы потребностей и кнопки действий (поповер из меню-бара или по клику на питомца)
- [ ] Анимации: `eat`, `happy`, `sad`, `sleep`, `hungry`

## M3 — Живое поведение

**Итог:** питомец сам находит себе занятия и замечает пользователя. Это то, ради чего всё затевалось.

Мозг
- [ ] `Activity` как прерываемый сценарий из шагов
- [ ] `Brain`: оценка занятий по потребностям, времени суток, недавним событиям + случайность
- [ ] Приоритеты и прерывания (взяли на руки > еда > игра > безделье)
- [ ] Отладочная панель: текущее занятие, оценки кандидатов, ручной запуск занятия

Занятия
- [ ] Бытовые: побродить, сесть, лечь, зевнуть, почесаться, оглядеться
- [ ] Пробежка по экрану
- [ ] Следить взглядом за курсором
- [ ] Погоня за курсором
- [ ] Мячик: достать, толкать, гоняться (физика SpriteKit); пользователь может бросить мяч мышью
- [ ] Просить внимания, когда потребность низкая

Интерес к пользователю
- [ ] Сенсор простоя: ушёл / вернулся → встретить
- [ ] Сенсор активности: активно печатает → сесть рядом и смотреть / не отвлекать
- [ ] Время суток: вечером сонный, ночью спит
- [ ] Реакция на смену активного приложения (любопытство)

## После MVP

Крупные направления, порядок не определён. Подробности и мелкие идеи — в [IDEAS.md](IDEAS.md).

- **Мир вокруг** — хождение по окнам, лазанье по краям экрана, предметы и домик
- **Глубина тамагочи** — рост и стадии жизни, характер, болезни, инвентарь и разная еда
- **Игры** — мини-игры с питомцем, достижения
- **Ассистент** — напоминания, помодоро, перерывы, реакции на систему
- **Разум** — разговор через LLM, память о пользователе
- **Кастомизация** — скины, другие виды питомцев, несколько питомцев
