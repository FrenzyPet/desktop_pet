# Роадмап

Этапы идут по порядку; каждый заканчивается чем-то, что можно запустить и потрогать.
Сроков нет — проект делается в свободное время. Задача отмечается галочкой, когда она в `main`.

Правило: задачи следующего этапа уточняются, когда до него дошли. Дальние этапы — наброски.

Питомец — Сенека, кот-мудрец породы мейн-кун. Его характер описан в [VISION.md](VISION.md);
все занятия и анимации ниже подобраны под него.

## M1 — Сенека на экране

Оверлей

- [ ] По итогам спайка подтвердить или пересмотреть решение №1 в [ARCHITECTURE.md](ARCHITECTURE.md)
- [ ] Клики проходят насквозь везде, кроме кота
- [ ] Окно поверх обычных приложений, на всех Spaces; поведение в полноэкранных приложениях
- [ ] Пол: нижняя граница рабочей области с учётом Dock

Спрайты и анимация
- [ ] Формат манифеста анимаций (JSON) и загрузчик
- [ ] Первый черновик Сенеки от Claude, кадр 64×48, сразу в эталонной палитре:
      `sit`, `walk`, `loaf`, `fall`, `held`
- [ ] Оценить черновик: годится ли такой способ рисования для MVP или нужна модель под
      пиксель-арт / готовый набор
- [ ] Эталонная палитра с ролями цветов (основа, тень, полосы, манишка, носочки, контур, глаза, нос)

## M2 — Тамагочи

**Итог:** у Сенеки есть потребности, за ним можно ухаживать, состояние переживает перезапуск.

Ядро
- [ ] Модель потребностей: сытость, энергия, настроение и скорости убывания
- [ ] `Mood` — производное состояние с порогами и гистерезисом
      (безмятежен / доволен / скучает / голоден / сонный / отстранён)
- [ ] Сон: кот спит много и короткими заходами; засыпание, восстановление энергии, пробуждение
- [ ] `WorldEvent` / `PetCommand` — контракт между ядром и оболочкой
- [ ] Офлайн-догон с ограничением сверху
- [ ] Тесты сценариев («6 часов без еды», «ночь сна», «неделя офлайн»)

Сохранение
- [ ] `PetState` в JSON, версия схемы, сохранение по таймеру и при выходе
- [ ] Выбранные окрас и цвет глаз хранятся в `PetState`
- [ ] Поведение при битом/старом файле

Уход
- [ ] Кормление: миска появляется на сцене, кот подходит и ест
- [ ] Поглаживание: распознать движение мыши по коту → мурчит, жмурится
- [ ] Предел терпения: перегладили — встаёт и уходит, настроение чуть падает
- [ ] Окно статуса: шкалы потребностей и кнопки действий (поповер из меню-бара или по клику на кота)
- [ ] Анимации: `eat`, `purr`, `sleep` (клубком), `hungry_stare`, `aloof`
- [ ] Хвост как индикатор настроения: варианты `sit`/`walk` с разным положением хвоста

## M3 — Живое поведение

**Итог:** Сенека сам находит себе занятия и замечает пользователя. Здесь появляется характер —
это то, ради чего всё затевалось.

Мозг
- [ ] `Activity` как прерываемый сценарий из шагов
- [ ] `Brain`: оценка занятий по потребностям, времени суток, недавним событиям + случайность
- [ ] Приоритеты и прерывания (взяли на руки > еда > охота > игра > созерцание)
- [ ] Темперамент как параметры мозга: спокойные занятия весят больше, вспышки активности редкие
- [ ] Отладочная панель: текущее занятие, оценки кандидатов, ручной запуск занятия

Кошачий быт
- [ ] Умывание, потягивание, зевок, почесаться за ухом
- [ ] Побродить, сменить место, улечься буханкой
- [ ] Редкий «тыгыдык» — внезапная пробежка через весь экран, после которой делает вид, что ничего не было

Мудрец
- [ ] Созерцание: сидит неподвижно, смотрит вдаль, медленно моргает
- [ ] Наблюдение за работой: садится рядом с курсором и смотрит на тебя
- [ ] Стоическая просьба: потребность низкая → подходит, садится и молча смотрит

Охотник (срыв невозмутимости)
- [ ] Следить взглядом за курсором
- [ ] Охота на курсор: замереть → вильнуть задом → прыжок → «промахнулся, так и было задумано»
- [ ] Мячик: достать, гонять лапой (физика SpriteKit); пользователь может бросить мяч мышью
- [ ] Апорт: приносит брошенный мяч обратно к курсору

Изречения
- [ ] Облачко с короткой репликой над котом; локальные данные, без сети и LLM
- [ ] Формат реплики: текст + условия (занятие, настроение, время суток, событие) + тон
- [ ] Выбор реплики в ядре: подходящие по ситуации, без повторов подряд, с редкой частотой
- [ ] Стартовый набор: по несколько реплик на каждое занятие и состояние

Интерес к пользователю
- [ ] Сенсор простоя: ушёл / вернулся → просыпается, идёт встречать
- [ ] Сенсор активности: активно печатаешь → не отвлекает, лежит рядом
- [ ] Время суток: днём дремлет, оживляется утром и вечером, ночью спит
- [ ] Реакция на смену активного приложения (поворачивает голову, иногда идёт посмотреть)

## После MVP

Крупные направления, порядок не определён. Подробности и мелкие идеи — в [IDEAS.md](IDEAS.md).

- **Мир вокруг** — хождение по окнам, лежанка, коробка, когтеточка
- **Глубина тамагочи** — привязанность, разная еда, предпочтения, дневник кота
- **Игры** — лазерная указка, удочка-дразнилка, достижения
- **Наставник** — напоминания и перерывы в стоическом духе, помодоро, вечерний обзор дня
- **Разум** — беседы с Сенекой через LLM, память о пользователе
- **Кастомизация** — новые окрасы, аксессуары, формат «пак питомца» для других персонажей
