# Desktop Pet

Настольный питомец-тамагочи для macOS. Личный долгий проект, без дедлайнов.

## Перед работой

- Текущий план и статус задач — `docs/ROADMAP.md`. Закрыл задачу — отметь галочкой.
- Решения и их причины — `docs/ARCHITECTURE.md`. Меняешь решение — обнови документ в том же изменении.
- Новые идеи не реализуются на ходу, а записываются в `docs/IDEAS.md`.

## Правила

- Вся логика питомца живёт в `PetCore` и покрыта тестами. `PetCore` не импортирует AppKit/SpriteKit,
  не читает системные часы и не использует глобальный генератор случайных чисел — время и случайность
  приходят параметрами.
- `DesktopPet` (оболочка) только отображает и передаёт события, решений о поведении не принимает.
- Без сторонних зависимостей, пока нет явной необходимости.
- Документы и комментарии в коде — на русском, идентификаторы — на английском.

## Команды

- `make run` — собрать и запустить
- `make test` — тесты (именно через make: без Xcode голый `swift test` не находит плагин Swift Testing)
- `make format` — форматирование
