# Desktop Pet

Настольный питомец-тамагочи для macOS. Питомца зовут **Сенека** — это кот-мудрец породы мейн-кун.
Он живёт поверх рабочего стола, созерцает, наблюдает за тобой, иногда срывается в охоту на курсор,
и за ним нужно ухаживать — кормить, гладить, играть.

Личный проект, разрабатывается без спешки. Сейчас — стадия **M0: фундамент**.

## Запуск

Нужен macOS 15+ и Swift 6 (хватает Command Line Tools, полный Xcode не обязателен).

```bash
make run     # собрать и запустить
make test    # тесты ядра
make format  # отформатировать код
```

Сейчас приложение показывает оранжевый квадрат-заглушку внизу экрана и значок 🐾 в меню-баре
(через него — выход).
